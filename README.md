# Expense Tracker

A Python application for managing expenses, calculating totals, and storing data in JSON format.

## Features

- Add new expenses
- Remove expenses by ID
- Display all expenses
- Calculate the total of all expenses
- Filter expenses by category
- Calculate monthly expenses
- Calculate totals by category
- Sort expenses by amount

## Technologies Used

- Python
- JSON
- Object-Oriented Programming (OOP)
- "datetime" module

## Project Structure

```text
expense-tracker/
├── main.py
├── models.py
├── expense_manager.py
├── storage.py
├── expenses.json
└── README.md
```

## How to Run

1. Make sure Python is installed on your computer.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python main.py
```

## Data Storage

Expenses are stored in a JSON file, allowing the application to save and reload data between sessions.
